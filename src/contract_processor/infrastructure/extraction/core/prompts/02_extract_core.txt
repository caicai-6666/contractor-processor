【最高优先级规则】
1. 字段定义中的 field_id、meaning、aliases、not_meaning、output 和 extraction_rule 是唯一字段语义依据。
2. examples 只说明边界和格式，不是当前合同事实，不得复制示例值。
3. 合同理解地图仅帮助定位；所有最终结论必须回到当前合同图像核验。
4. fields 必须是以 field_id 为键的对象，只包含当前字段定义中的唯一 field_id，不得增加或遗漏。
5. 顶层只输出 fields，不得输出 document_id，不得生成根级 reason；document_id 由程序根据原始 PDF 文件字节计算。
6. 非 object 字段严格按 raw_value、reason、status、value 输出。reason 必须先基于已经摘录的 raw_value 简述采用、缺失、冲突或排除依据，再以固定输出决定收尾：选择 found 时写“所以接下来的 status=found，value=非 null。”；选择空值状态时写“所以接下来的 status=状态名，value=null。”，并将“状态名”替换为实际选择的 not_found、ambiguous、conflicting、not_applicable，object 直属子字段还可使用 out_of_scope。随后输出的 status 和 value 必须与该决定完全一致；整个 reason（含固定输出决定）不得超过 300 个字符，不得展开完整思维链。
7. object 字段不得生成外层 raw_value、reason、status 或 value，只生成 properties；对象外层 status 由程序汇总。每个直属子字段严格按 raw_value、reason、status、value 的顺序输出。
8. 只提交一次最终 JSON；不得在 JSON 后重新进入 `<think>`、生成第二份 JSON、添加注释或声明。

【状态与值】
1. found：存在唯一可采用的结果，value 非 null。
2. not_found：已检查可见页面但未发现，value 必须是 JSON 字面量 null，不得输出子字段全为 null 的对象。
3. ambiguous：存在相关候选但语义或归属无法消歧，value 为 null，并在 status 之前的 reason 中说明。
4. conflicting：存在互不相容的结果，value 为 null，并在 status 之前的 reason 中说明。
5. not_applicable：该字段对当前合同明确不适用，value 必须是 JSON 字面量 null，不得输出空对象。
6. object 直属子字段额外允许 out_of_scope：合同中存在相关原文，但它不属于该子字段可采用的业务口径。此时保留相关 raw_value，在 status 之前的子字段 reason 中说明排除原因，value 为 null。
7. 非 object 字段的 not_found、not_applicable、ambiguous、conflicting 都必须令 value 为 JSON null。raw_value 可为 null；存在相关但不足以形成可采用值的原文时，可保留最小相关原文供审计，不得将其复制到 value。
8. object 子字段中，not_found/not_applicable 的 value 必须为 null，raw_value 可为 null 或最小相关原文；ambiguous/conflicting/out_of_scope 必须保留相关 raw_value 且 value 为 null。不得用空字符串或全 null 对象代替 null。

【原始值与规范化】
1. raw_value 保存当前合同图像中可见的最小必要原始文字；多个原始值以简短字符串组合，不得写入解释性推理。raw_value 不得填写 lower_snake_case 枚举代码、规范值对象或模型分类结果；原文只支撑分类但没有逐字出现枚举代码时，应摘录支撑分类的合同原文。
2. 日期、金额、币种、枚举和受控分类必须符合字段 output.format。
3. 不得按甲乙方顺序猜测业务角色；主体原文名称和称谓不得改写。
4. 只有当前字段定义的 extraction_rule 明确允许且计算输入口径一致时才能计算；不得展示推理过程。
5. object 的 output.properties 中所有直属子字段都必须输出独立包络，不得省略。数组作为一个直属子字段处理，不递归包裹数组元素内部属性。
6. 当前字段涉及金额、税率或费用时，判断和计算前必须核对“合同理解条目”中的“金额与费用原文清单”，并回到合同图像复核；清单与图像冲突时以图像为准。
7. 子字段为 null、not_found、not_applicable 或 out_of_scope，只表示该局部结果不可采用，不等于整个 object ambiguous。对象外层状态由程序汇总，不得自行输出。
