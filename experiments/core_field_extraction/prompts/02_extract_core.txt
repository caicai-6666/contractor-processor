【最高优先级规则】
1. 字段定义中的 field_id、meaning、aliases、not_meaning、output 和 extraction_rule 是唯一字段语义依据。
2. examples 只说明边界和格式，不是当前合同事实，不得复制示例值。
3. 合同理解地图仅帮助定位；所有最终结论必须回到当前合同图像核验。
4. fields 必须是以 field_id 为键的对象，只包含当前字段定义中的唯一 field_id，不得增加或遗漏。
5. 顶层严格按 document_id、fields 的顺序输出，不得生成根级 reason。
6. 非 object 字段严格按 raw_value、reason、status、value 输出。reason 基于已经摘录的 raw_value 简述采用、缺失、冲突或排除依据，再据此选择 status；不得展开完整思维链。
7. object 字段不得生成外层 raw_value、reason、status 或 value，只生成 properties；对象外层 status 由程序汇总。每个直属子字段严格按 raw_value、reason、status、value 的顺序输出。
8. 只提交一次最终 JSON；不得在 JSON 后重新进入 `<think>`、生成第二份 JSON、添加注释或声明。

【状态与值】
1. found：存在唯一可采用的结果，value 非 null。
2. not_found：已检查可见页面但未发现，value 必须是 JSON 字面量 null，不得输出子字段全为 null 的对象。
3. ambiguous：存在相关候选但语义或归属无法消歧，value 为 null，并在 status 之前的 reason 中说明。
4. conflicting：存在互不相容的结果，value 为 null，并在 status 之前的 reason 中说明。
5. not_applicable：该字段对当前合同明确不适用，value 必须是 JSON 字面量 null，不得输出空对象。
6. object 直属子字段额外允许 out_of_scope：合同中存在相关原文，但它不属于该子字段可采用的业务口径。此时保留相关 raw_value，在 status 之前的子字段 reason 中说明排除原因，value 为 null。
7. 非 object 字段沿用严格空状态规则：not_found、not_applicable、ambiguous、conflicting 的 raw_value 和 value 都必须为 JSON null。
8. object 子字段中，not_found/not_applicable 的 raw_value 和 value 都必须为 null；ambiguous/conflicting/out_of_scope 必须保留相关 raw_value 且 value 为 null。不得用空字符串或全 null 对象代替 null。

【原始值与规范化】
1. raw_value 保存当前合同图像中可见的最小必要原始文字；多个原始值以简短字符串组合，不得写入解释性推理。
2. 日期、金额、币种、枚举和受控分类必须符合字段 output.format。
3. 不得按甲乙方顺序猜测业务角色；主体原文名称和称谓不得改写。
4. contract_validity_period 只接收合同整体有效期。货期、交付期、服务完成期、工期、付款期、质保期不得写入；签订日期或生效日期本身也不得作为 start_date，除非合同明确将该日期定义为整体有效期或整体合作期的起点。
5. 条件生效必须写入 effective_mechanism.trigger_type 和 trigger_text；不能因为没有确定日期而丢弃条件。
6. 金额先判断 amount_type。框架无总额、仅单价或据实结算可以是 found 且 amount 为 null。
7. 只有字段规则明确允许且计算输入口径一致时才能计算；不得展示推理过程。
8. object 的 output.properties 中所有直属子字段都必须输出独立包络，不得省略。数组作为一个直属子字段处理，不递归包裹数组元素内部属性。
9. 当前字段涉及金额、税率或任何费用时，判断和计算前必须逐条核对“合同理解条目”中的“金额与费用原文清单”，并回到合同图像复核。每一个计算输入都必须同时得到该清单和图像支持；清单出现运费、保险费、服务费等费用组成时必须纳入口径比较，不得只取总额和税率计算。清单遗漏或与图像冲突时以图像为准，在相关子字段 reason 中简述差异，并禁止使用清单未覆盖的输入进行计算。
10. 子字段为 null、not_found、not_applicable 或 out_of_scope，只表示该局部结果不可采用，不等于整个 object ambiguous。对象外层状态由程序汇总，不得自行输出。
11. contract_amount 不输出独立未税金额子字段。合同中的未税价格、未税总额或不含税总价仍必须保留在 source_amount_text，不得遗漏，也不得生成字段定义之外的额外属性。合同级总额、金额性质、含税属性或明示税率存在唯一可采用结果时，相应子字段必须为 found，不得因未税金额不再独立输出而把 contract_amount 或其他明确子字段标为 ambiguous。
